# Architecture
Modular monolith. `http/*` handlers (thin) → domain modules (`reconciliation::{engine,rules,service}`, `discrepancies`, `disputes`, `billing`, `workers`) → PostgreSQL. The engine is a pure function (no I/O, no floats); `service.rs` loads inputs and persists outputs. Every tenant request: authenticate (`AuthedUser`) → `rbac` permission → `begin_scoped_tx` (RLS context) → `ensure_owned` for referenced ids → mutate → `audit::record` in the same transaction. Provider seams: `storage::ObjectStorage` (local FS implemented), `extraction::DocumentExtractor` (plain text implemented; no OCR). The Next.js app is a thin client behind a same-origin BFF proxy.
