# API (all under /api/v1, JSON, `Authorization: Bearer <session>` except health/auth/webhook)
Auth: `POST /auth/signup|login|logout`, `GET /me`. Data: `/vendors`, `/contracts` (+`/contracts/:id/rates`, `PUT /rates/:id/end`), `/invoices` (+`PUT /invoices/:id/manifest`), `/manifests`, `/weight-tickets` (GET list/detail, POST create). Documents: `POST /documents?document_type=&filename=` (raw body, `Content-Type` = file type), `GET /documents[/:id[/download]]`. Workflow: `POST /reconciliations/run`, `GET /reconciliations[/:id]`, `GET /discrepancies[?status=]`, `POST /discrepancies/:id/review {action,notes}`, `GET|POST /discrepancies/:id/evidence`, `GET /discrepancies/:id/evidence/pdf`, `GET|POST /disputes`, `POST /disputes/:id/transition {to,amount?,credit_memo_reference?}`, `GET /recovery`, `GET /dashboard`. Admin: `GET|POST /members`, `GET /audit`, `GET /notifications`, `POST /notifications/:id/read`, `POST /monitoring/run`, `GET /monitoring/jobs`, `GET /billing/status`, `GET /billing/checkout-context` (OWNER/ADMIN), `POST /billing/paddle/webhook` (signature-authenticated), `POST /documents/:id/resolve`.
Errors: `{"error":{"code","message"}}` with 400/401/402/403/404/409/413/503. Money/quantities: send decimal strings; receive 4-decimal strings. Reconciliation responses include `pricing_status` (`COMPLETE`, `PARTIAL`, `UNCOMPUTABLE`, or `LEGACY_UNVERIFIED`). For non-complete pricing, `expected_amount` and bill-level `discrepancy_amount` are `null`; partial results may include `partial_expected_amount`, which is only a diagnostic subtotal. `identified_finding_amount` sums amounts attached to findings and must not be interpreted as total invoice exposure when pricing is incomplete.
