# Deployment
1. Provision Postgres 16. 2. Run `scripts/migrate.sh` with a privileged role and `XFLOW_APP_PASSWORD`. 3. Run the backend as `xflow_app` (never a superuser: RLS would be bypassed). 4. Run the web app with `API_INTERNAL_URL` pointing at the backend. 5. Terminate TLS at a proxy in front of `web` (cookies are Secure in production). 6. Route only `/api/v1/billing/paddle/webhook` from the internet to the backend and set `PADDLE_WEBHOOK_SECRET`. 7. Persist `STORAGE_DIR`. 8. Set `PADDLE_CLIENT_TOKEN`, `PADDLE_PRICE_ID`, `PADDLE_ENV` on the web app and configure the Paddle notification destination (see docs/billing.md). 9. The backend needs `pdftotext` (poppler-utils) for PDF text extraction; the image installs it. `docker-compose.yml` is a single-host reference — **never built or run by the author (no Docker in the sandbox)**; CI builds both images and runs the browser e2e.
